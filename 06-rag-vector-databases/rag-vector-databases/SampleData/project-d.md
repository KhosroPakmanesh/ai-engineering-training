# Birch reporting dashboard

## Weekly reports

Mira built a C# console report for a fictional bicycle rental shop. It read CSV rental records, grouped rentals by bicycle category, and wrote a weekly HTML summary. Invalid dates were collected into an error report before totals were accepted.

## Review workflow

The shop coordinator reviewed the generated tables against the source records. Mira added clear labels for missing return dates and a total of excluded records. The prototype used local files and did not connect to a hosted analytics service.
