# Maple accessible catalog

## Catalog pages

Mira helped build a fictional seed catalog using HTML, CSS, and JavaScript. She added keyboard navigation, visible focus indicators, and descriptive labels to the filter controls. The catalog used a small static JSON list of products.

## Usability checks

Mira checked whether all filters could be operated without a mouse. She corrected a focus trap and improved text contrast. The notes describe manual checks rather than a claim of complete accessibility certification.
