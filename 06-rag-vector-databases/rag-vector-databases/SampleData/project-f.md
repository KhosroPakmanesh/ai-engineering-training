# Rowan document review

## Editorial work

Mira proofread fictional software onboarding notes. She corrected spelling, clarified a release checklist, and aligned headings across six documents. This project involved editing text rather than implementing the systems described in the notes.

## Source checks

Reviewers compared each changed instruction with the team's approved checklist. Unclear technical claims were returned to the author for confirmation. Mira tracked unresolved questions explicitly instead of filling in missing facts.
